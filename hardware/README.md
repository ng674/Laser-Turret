# Hardware context

This directory contains purchasing evidence and integration assumptions, not
approval to purchase, wire, or energize components.

- `PARTS.md`: consolidated engineering view of the parts and unresolved items.
- `PROCUREMENT.md`: dated procurement planning and budget notes.
- `reference/Laser_Turret_Parts.pdf`: original user-supplied parts sheet.

Mechanical source and printable files live under `cad/turret_v8_K1Max/`.

The first physical milestone is laser-free: camera, clamped structure, servos,
controller, feedback logging, manual stop, and LED dummy. Actual dimensions,
connector ratings, spline interfaces, fastener engagement, and supply behavior
must be verified from delivered components before physical integration.
